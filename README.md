# 🍽️ Restaurant Ordering System

A full-stack restaurant ordering system that allows customers to scan a QR code at their table, view the menu, and place food orders.

## ✨ Features

### Customer

- Scan table QR code
- View restaurant menu
- Search and filter food
- Add items to cart
- Place orders
- Track order status

### Kitchen

- View incoming orders
- Start preparing orders
- Mark orders as completed
- Cancel orders
- Receive orders in real time

### Manager / Admin

- View restaurant analytics
- Manage menu items
- Enable/disable menu items
- Archive menu items
- Generate table QR codes

## 🛠️ Technologies

- **Frontend:** React, Vite, Tailwind CSS
- **Backend:** Node.js, Express.js
- **Database:** MySQL
- **Real-time:** Socket.IO
- **Database Management:** XAMPP / phpMyAdmin
